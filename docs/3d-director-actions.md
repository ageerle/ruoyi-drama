# 在白模中编排动作

3D 导演工作台是预览功能，尚未正式发布。它用于提前排好人物动作、空间关系和运镜，再输出白模参考视频。当前有 17 个可编辑关节，支持最长 60 秒的编排，也可以用「参考视频动作」在本机提取单人视频中的姿态。提取后仍需检查和修正；手指抓握、脚底水平锁定、碰撞接触和真实动捕表演还没有接入。完整操作见[从参考视频复刻动作](tutorials/reference-motion/README.md)。

进入项目的流程设计器，添加「3D 导演」节点。已有节点可以直接重新打开。右上角「操作参考」也是本篇的内置版本；空场景可点击「载入双人动作练习」，打开十二秒的完整练习。载入按钮只在空场景启用，已有工程要保留时，回到画布新建另一个节点。

## 先分清三种编辑

| 页面入口 | 负责什么 | 一个例子 |
| --- | --- | --- |
| 人物属性 → 走位 | 世界坐标、朝向、尺寸、移动插值 | 来客从门口走到另一人面前 |
| 人物属性 → 动作编排 | 动作片段、开始和结束、速度、幅度、首尾过渡 | 先行走，再招手，然后伸手 |
| 人物属性 → 关节姿态 | 躯干、头、左右肩肘髋膝的旋转微调 | 伸手时再弯肘，停下后回头 |

人物位移与动作分开：加入「行走」只让腿和手臂运动，必须另设位置关键帧，人物才会前进。关节姿态叠加在基础动作和动作片段上，既可把动作调得更明确，也可只用「站立」基础动作，从零编排姿势。

## 练习一：走过来，再抬手

1. 添加人物，片段长度设为 8 秒。在「走位」将基础动作设为站立，第 0 帧位置设为 `X=-3.2, Y=0, Z=0`。朝向设为 90 度，或勾选「沿路线自动朝向」。人物正前方是自身的 +Z。
2. 下方「当前预演帧」输入 `72`，将 X 改为 `-0.75`。这会自动记录 3 秒处的位置。切回第 0 帧，把「到下一关键帧的移动」设为匀速或缓入缓出。
3. 回到第 0 帧，打开「动作编排」，点击「行走」。默认加入两秒片段，把结束秒数改成 `3`。动作库按钮在当前时刻有片段时禁用；移到空白时段就能继续添加。
4. 输入第 `72` 帧，添加「招手」，开始为 3 秒、结束为 5 秒。再输入第 `120` 帧添加「伸手」，结束设为 8 秒。首尾过渡推荐先使用 6–12 帧。
5. 空格播放，先检查人物是否真的到达目标位置，再看动作时机。速度改变摆臂、迈步或点头的节奏，不会改变片段时长；幅度 0% 接近基础姿态，100% 为预设幅度。

动作片段采用开始含、结束不含的时间范围。同一人物的片段不能重叠，两个不同人物可以同时做动作。点击时间轴上的蓝色动作条，会选中人物、定位到片段开头，并打开对应的编辑参数。片段可删除或「接在后面复制」；如果后面已有动作或超过片段总长，修改会被拒绝，原数据保留。

## 练习二：自己设计抬手和弯肘

这个练习可不用动作库。选中人物，基础动作设为站立，时间轴移到第 0 帧。在「关节姿态」记录右上臂、右肘为零偏移，作为动作起点。

在第 24 帧将右上臂 X 设为 -75 度、右肘 X 设为 -20 度；第 48 帧将右肘 X 改为 -55 度；第 72 帧点击「清除当前帧全部姿态微调」。播放时会从站姿抬手、弯肘，再放下。每次修改自动记录当前帧，因此先记录起点零偏移，可以避免姿态从更早的时刻就开始变化。

「X · 前后弯曲」「Y · 左右转动」「Z · 侧向抬起」的方向以所选关节的局部坐标为准；人物整体转身后，世界方向会随之改变。先点击「聚焦选择」放大人物，再用顶部「姿态」工具在所选身体部位显示旋转环，也可直接点白模身体部位更换关节。数字、滑杆和视口旋转环编辑的是同一份关键帧。

姿态模板是起步用的旋转组合，点击后可继续改。「复制姿态」复制当前的关节偏移，移到其他帧或选择另一人物后可以粘贴；「左右镜像」把左右肢体互换，并反转转头和侧向旋转。身体高度偏移用于下蹲或整体起伏，允许 -0.9 到 1 米。它不会自动调整脚底接触，需自己检查姿态是否穿地。

如果要精确控制头部角度，在「走位 → 头部持续注视」中选择自由姿态。持续注视会叠加朝向目标的头部水平转动，自动转动限制为左右各 70 度，超过范围时应调整身体朝向。

## 练习三：双人回应与摄影机

十二秒练习的默认编排如下。它是空间与动作时序练习，伸手回应没有手持物体或精确抓握。

| 时间 | 来客 | 等候者 | 镜头 |
| --- | --- | --- | --- |
| 0–3 秒 | 从 X=-3.2 走到 -0.75 | 站在 X=1 | 保持双人中远景，开始缓慢靠近 |
| 3–5 秒 | 招手 | 3.5–5 秒点头 | 转向人物之间 |
| 5–9 秒 | 伸手，右肘和躯干再做微调 | 6–9 秒伸手回应 | 靠近并绕到另一侧 |
| 9–12 秒 | 点头后回到站立 | 交谈手势 | 停在双人构图 |

选择「摄影机」，第 0 帧与后续时刻分别设置机位坐标、拍摄目标和 FOV；「到下一机位的移动」可以选择匀速、缓入缓出或保持后切换。右下角「摄影机监看」是最终导出的构图，编辑视口的旋转不会改变输出机位，除非点击「当前视角设为机位」。

需要持续跟拍时，在「持续跟随目标」中选择人物：

- 「只跟随视线」保持原机位路线，拍摄目标实时落到人物身上，适合推拉、绕拍时维持主角构图。
- 「机位与视线一起跟随」使用固定的世界坐标偏移，人物移动多少，机位就移动多少。偏移可以分别调整，不会自动绕开墙体。
- 「注视高度」控制目标落在腰部、头部还是更高位置。关闭跟随后会把当前构图记录为机位关键帧，可以继续手动编辑。

## 调整节奏和保存

时间轴上的菱形是位置、朝向和姿态关键帧。拖动可改时刻，按住 Alt 拖动可复制；第 0 帧不能移动，但可以复制。键盘回车可选择关键帧。右侧关键帧列表也可点选，再输入「关键帧目标时间」，选择复制或移动。目标时刻已有关键帧时会提示冲突，不覆盖原帧。

对象锁定后不能改位置、尺寸、动作、关节或关键帧。Ctrl+Z 撤销，Ctrl+Shift+Z 重做；空格播放，Ctrl+S 保存。工程在停止编辑后自动保存，返回画布前也会等待保存。JSON 包含动作片段、关节姿态、注视关系和摄影机跟随；首版工程仍可直接打开。

播放检查通过后再「导出白模视频」。浏览器按同一份姿态计算输出 H.264 MP4，24 fps，横屏 1280×720、竖屏 720×1280；没有声音、网格和旋转环。导出完成会出现回放窗口，可以核对动作是否连贯、构图有没有切断人物。该功能仍未接入 AI 视频参考生成。
