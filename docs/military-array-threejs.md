# 一字长蛇阵军阵预演

项目新增了 HTML + Three.js 军阵页面，开发服务启动后访问 `/demos/long-snake/index.html`。花树预演页右上角也有“军阵预演”入口。该功能仍是试制预演，供队形、走位和镜头参考使用。

默认总兵力 360 人，4 排并行，纵深 90 列，包含 72 名骑兵、59 名盾兵、164 名枪兵、59 名弓兵和 6 名旗手。骑兵占 20%，放在前段，盾兵、枪兵与弓兵在其后编排。骑兵和旗手都计入总兵力，一骑按一名骑手计数。

骑兵以整列分配，比例可以调到 0–50%，实际人数会随兵力、排数取整。马匹前后中心间距为 3.5 米，步兵默认 1.25 米；骑步混编时横向间距至少 1.45 米，默认队列中心长度约 151.8 米。设为 0% 后恢复纯步兵，长度约 111.3 米。

## 操作参考

1. 选择“一字列阵”，切换“俯视总览”，先查看蛇首、蛇身、蛇尾的位置。右侧可调整兵力、并行排数和间距。总兵力允许 24–960 人，并行排数可选 1、2、3、4、6 排。
2. 调整“骑兵比例”，再选择“沿线行军”和“骑兵近景”。马匹会交替迈腿，骑手跨坐在马鞍上持枪，配有缰绳、镫环、鬃毛、尾巴与蹄。用“暂停行军”或空格暂停，用“从头演示”重新播放。时间轴及其右侧秒数框可直接定位。
3. 选择“蛇行转向”，调整弯幅，观察各排沿弯曲路径前进。纵向位置按路径长度排列，避免仅压缩横坐标造成转弯挤成一团。
4. 选择“首尾照应”，队列从直线逐渐内收为弧形。骑兵保持沿弧线的朝向，步兵转向中部红圈，避免马匹横向转身挤入相邻排。点击“查看展开”可暂停在本段时长的 72% 位置；默认 24 秒、1 倍速时已完成内收。调整速度会改变动作进度，0 倍速停止动作。
5. 切换各部位的近景看人物与装备。拖动画面旋转，滚轮缩放，右键平移。点击兵卒身体或马身可查看所属部位、列数、排数和兵种，地面会显示选中圈。“骑兵近景”持续跟随马队；骑兵为 0 时该按钮不可用。
6. 右侧的“队列引导”“部位标注”“步尘”可以单独关闭。导出干净的镜头参考时，可先关闭引导与标注，再拖动到需要的视角。

## 保存配置与导出视频

参数会在当前浏览器本地保存。点击“导出配置”可保存 JSON；“导入配置”恢复兵力、骑兵比例、动作、间距、速度、弯幅、时长及显示开关。导入文件最大 64KB，并检查字段和取值范围。配置不保存手动旋转后的机位。旧版 JSON 缺少 `cavalryPercent` 时按 0% 导入，保留原步兵编排；需要骑兵时手动调整比例或点击“恢复默认军阵”。

视频录制范围是整段动作，从第 0 秒开始。先选动作、调整镜头，再点击“导出当前机位 MP4”。当前观察方向会保留，近景会继续跟随对应部位。横屏为 1280×720，竖屏为 720×1280，均为 24fps、无声 H.264 MP4；时长可设 6–30 秒。竖屏会重新拉远以容纳原来的观察范围。导出期间暂停实时预演，可以取消；完成后在页面下方回放或点击下载链接保存。

长蛇队形、兵种分区和通用古装是本次数字编排。首尾相应的表达参考《孙子兵法·九地》中的“率然”比喻，可参阅[原文](https://zh.wikisource.org/wiki/孫子兵法#九地第十一)。该段原文没有规定这里采用的兵种比例、装备或排数，本页面不作为特定朝代的军阵复原。

## 实现与验证

源代码位于 `src/features/military-array/`，`model.ts` 负责队形路径与时序，`scene.ts` 负责实例化兵卒、兵器、镜头和选择，`export.ts` 逐帧生成 MP4，`main.ts` 连接控件与配置。HTML 入口位于 `public/demos/long-snake/index.html`。运行 `npm run build:military-array` 重新生成本地脚本，完整 `npm run build` 也包含这个步骤，无需外部 CDN 或新增依赖。

目前是独立军阵预演页面，尚未写入短剧项目的导演工作台工程。人物与马匹是程序化模型，迈步采用关节摆动，没有脚部 IK、地形避障、交战碰撞或真实布料模拟；可用于生成视频的动作参考，精细成片需要后续替换人物与场景资产。

骑兵版验证包括 8 个模型测试、TypeScript 检查及生产构建。新增测试覆盖骑兵人数取整、旧配置兼容，以及小间距、六排、多种兵力下转弯和内收的马匹矩形占地分离；这不等于真实交战碰撞模拟。实际浏览器检查了 72 骑默认场景、比例切换、马身选择、骑步混编配置、转向与首尾内收、桌面及窄屏排版。骑兵近景的 6 秒、360 人、横屏 MP4 在页面中完整播放到末尾，媒体信息为 1280×720、6 秒，无播放错误。渲染日志未出现警告或错误。竖屏导出、最高兵力压力及触摸手势尚未实测；下载到操作系统文件的结果没有纳入验收。

渲染检查使用 `threejs-debug-profiler` 的 `debug-profile-checklists.md`、`scene-debugging.md`、`performance-profile.md`，均已读取。马匹复用几何、材质及实例化批次，没有逐骑新增独立网格。本次受控浏览器在增加骑兵前后均显示约 1fps，未完成稳定的前台帧率测量；增加骑兵前约 98 次绘制，骑兵近景约 132 次绘制，不能据此作真实设备帧率比较。完整记录保存在 `output/long-snake/qa-cavalry.json`。
