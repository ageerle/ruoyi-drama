# LibTV 画布操作与短剧编辑器设计

2026-10-04 使用 Edge 查看用户提供的《挺好的》副本画布。观察现有节点、空白右键、视频右键、分组右键和快捷键面板，没有在参考项目中创建、删除或生成素材。

## 实际观察

空白右键包含上传、添加节点、撤销、重做、粘贴。可添加文本、图片、视频、音频、脚本，以及导演台、智能剪辑、逐帧拉片和素材库。素材也能从上传、生成历史中进入画布。节点有输入和输出，选中后可编辑提示词及生成参数，参考素材以编号进入视频提示词。画布承担创作和修改，不只是展示制作结果。

视频节点右键包含复制节点、创建副本、删除、复制 TaskId、核验结果、优化布局和素材相关操作。视频编辑面板显示图片及声音参考、模型、参考模式、画幅、分辨率、时长与生成数量，并有自动校验素材和智能引用。视频结果还提供高清、片段重拍、去字幕、音视频分离、截取首尾帧等工具。

图片节点提供替换素材、打光、多角度、九宫格、高清、元素编辑和图层分离等操作。声音节点提供截取、变速、智能切分、自定义切分、下载和替换素材。分组用于组织节点；快捷键面板列出成组、解组、复制节点与连线、连线、新建节点、选择与抓手、整理布局、撤销、缩放、生成等操作。上述工具只验证了入口和选中后的面板，没有验证实际生成或加工效果。

## 本项目的操作映射

| 节点 | 编辑内容 | 输入用途 | 现有执行路径 |
| --- | --- | --- | --- |
| 文本 | 故事想法、对白、制作笔记 | 传给剧本或图片/视频 | 仅保存画布草稿 |
| 剧本 | 完整正文、改写要求 | 接收文本，传给视频 | 保存剧本、改写、分析资产与拆镜 |
| 图片 | 角色/场景/道具/可选首帧、描述、参考图、模型 | 接收文本和图片，传给视频 | 角色造型、场景、道具原接口；首帧可上传 |
| 声音 | 所属角色、声音描述、样音台词 | 关联角色，传给视频作为说话人 | 原角色声音的生成、上传、试听和选用 |
| 视频 | 镜头内容、导演稿、模型、秒数、分辨率、可选首帧 | 剧本、角色、场景、道具、声音；视频连线表示镜头顺序 | 原分镜保存、生成、查询、请求恢复与合成 |
| 分组 | 名称、尺寸 | 组织及共同移动 | 独立画布文档 |

制作顺序由用户安排：新建空白短剧，写大纲和剧本，创建角色与场景，建立声音，逐个添加镜头并连接所需输入，保存到项目后生成，最后按画布顺序合成。结构模板只创建空节点与连接，不读取已完成镜头。也可主动导入当前剧本版本的项目素材。

画布编辑与制作数据分开保存。拖动、连线、改写节点会自动保存画布；“保存到项目”才调用业务接口；“生成”才提交对应任务。不会因为打开、复制、撤销或整理画布而自动消费模型额度。已有视频任务 ID、批准图片和承接附属字段继续由原流程管理，复制节点不复制业务 ID 和任务 ID。

目前采用逐节点执行，尚无整张图自动调度。LibTV 的导演台、逐帧拉片、智能剪辑、高清修复、图层分离、音频变速与切分没有在本轮新增。它们各自需要媒体处理、供应商能力或额外任务编排，不能用外观相同的按钮代替。
