# 短剧流程设计器

工作台提供“新建画布”和“流程设计器”。新建画布只创建项目，进入空白创作空间；现有项目首次进入也不会自动导入成片。使用“短剧结构模板”创建空的大纲、剧本、角色、场景、声音和视频节点，或在空白处右键逐个添加。已有素材由“导入项目素材”主动加入，按当前剧本版本导入镜头。

## 从零制作

1. 在文本节点写故事想法，连接到剧本节点；直接粘贴完整剧本或输入改写要求。
2. 在剧本节点保存正文，按需要使用“生成 / 改写”或“分析资产与拆分镜头”。这些操作走原业务路径，沿用后台默认技能与审阅规则。
3. 添加图片节点，选择角色造型、拍摄场景、固定道具或可选首帧。编辑描述，上传参考图片，选择已配置的模型，保存或生成候选。
4. 添加声音节点，选择或连接角色造型，填写声音描述与样音正文。保存到项目后可使用原声音面板生成、上传、试听和选用样音。
5. 添加视频节点，编辑镜头内容和连续导演描述，选择模型、可选秒数、分辨率。把所需剧本、角色、场景、道具和声音连入视频。首帧可选，未使用时不要求生成首帧。
6. 保存视频节点后逐镜生成、查询任务或恢复原请求。视频之间的连线确定前后镜头顺序，其余镜头按画布顺序参数排列；最后进入成片合成。

## 编辑操作

空白右键添加节点；节点右键编辑、复制、创建副本、成组、解组和从画布移除；连线右键移除。拖动输出端点连接到输入，或拉到空白处创建后续节点，也可在节点面板添加输入。连接检查类型和循环，一个声音节点关联一个角色，一个视频镜头只能应用一个场景。

Shift 拖动框选、Ctrl 点击多选、Ctrl A 全选。Ctrl C/V/D 复制、粘贴、创建副本；Ctrl G / Ctrl Shift G 成组与解组；Ctrl Z / Ctrl Shift Z 撤销与重做；Delete 移除；Ctrl S 保存；Ctrl 0 总览；V/H 切换选择与抓手。分组可编辑名称与尺寸，共同移动内部节点。左下角提供缩放、小地图与连线显示，顶部切换工作流和分镜板。

画布自动保存节点、内容、连线、分组和视口。“保存到项目”应用到业务数据，“生成”提交对应模型任务。复制节点保留内容和图片参考，清除业务 ID 与任务 ID；复制角色和声音时同步重映射所属角色。移除画布节点不删除数据库角色、视频或批准媒体；移除分组会解组。撤销布局和内容时保留已经创建的业务编号及任务关联，避免重复创建。

## 数据与运行

`FlowStudio.vue` 负责编辑空间，`dramaCanvas.ts` 负责图结构、输入规则、分组与复制，`useCanvasDocument.ts` 管理历史及保存，`useCanvasExecution.ts` 适配已有制作接口。画布使用 Vue Flow，沿用项目白蓝主题并按需加载。

后端新增 `ShortDramaCanvasController` 和 `ShortDramaCanvasService`。GET/PUT `/short-drama/{projectId}/canvas` 检查项目所有权与版本，原子写入后端工作目录 `data/short-drama-canvases/<projectId>.json`，最多 500 节点、1500 连线、2MB。多窗口冲突会停止覆盖，先导出备份，再重新加载后合并。该目录需要随业务数据备份；多实例部署需要改成共享数据库存储。画布未能读取时不会当成空白文档覆盖。

已批准媒体、任务 ID、来源及承接附属字段由原制作业务保留。角色引用维护 `charactersJson`，场景维护 `locationName`，道具维护 `visible_props`，声音维护明确的 `voice_speakers`。未显式配置声音时保留既有自动匹配。未知视频提交仍由原请求恢复处理；未知图片提交暂停重发，需核对供应商任务。

原第一版查看入口保留为“素材关系图”，用于现有素材和历史剧本版本。该查看器的位置仍保存在浏览器，新编辑器使用独立后端文档。设计器目前逐节点执行，尚无整图自动调度。现已接入「3D 导演」预览节点，可从空场景编辑白模、动作和运镜，详细操作见 `3d-director.md`；白模视频参考尚未接入 AI 生成。LibTV 的智能剪辑、逐帧拉片、图层分离、高清修复及音频剪辑未实现。

工作台将两个入口明确标为“素材关系图”和“自由画布”。素材关系图直接显示项目已有分镜；自由画布显示独立保存的编辑节点，节点少不表示项目分镜被删除。自由画布顶部的“整集分镜 · N 镜”可返回已有分镜，切换前保存未完成的画布编辑，不自动导入或覆盖节点。

当前页面由 URL 恢复：`view=references` 打开素材关系图，`canvas=1` 打开自由画布。两种入口互斥，切换时清除另一种标记；关闭时一并清除。页面刷新、登录重定向及同路由查询参数变化按当前标记恢复，不再由临时弹层状态与遗留 `canvas=1` 各自决定打开哪个页面。

素材关系图只显示选中节点的相关连线：未选中节点时收起，选中镜头只显示本镜引用，选中素材只显示它关联的镜头；点击空白处或关闭检查面板即收起，不提供整图连线开关。相同起点与终点只画一条；角色形象和角色声音仍是不同引用，素材被多个镜头使用时保留各镜头绑定。查看连线不保存业务修改，也不删除引用、素材或已生成媒体。

## 验证

前端生产构建通过；图循环、输入类型、复制后的任务隔离与声音引用、分组移除、镜头顺序，以及原分镜引用、版本和视频请求恢复的 16 项测试通过。后端画布持久化、项目权限、版本冲突和无效图的 3 项测试通过，真实服务已重新构建并启动。

Edge 中创建了“《挺好的》· 从零制作画布”真实项目，初始为 0 节点。验证右键添加与节点菜单、节点内容编辑、结构模板、分组共同移动、复制副本、撤销恢复和输入连线移除/恢复。实际拖动声音输出连接到视频输入成功；刷新后恢复 8 个节点、6 条连线与已保存的内容和分组。剧本、角色造型、场景、声音设定和视频镜头已通过原接口保存到真实业务数据，填写内容均标明待补充原作；未生成图片、样音或视频，也未测试实际成片合成。没有提交付费媒体任务，也没有替换既有项目的批准媒体。
