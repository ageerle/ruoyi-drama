# RuoYi 导演工作台：武打动作设计教程

导演工作台为预览功能，尚未正式发布。本教程用可编辑关节白模排出一段 16 秒双人对练，展示准备、出拳、格挡、低踢、退步和收势。最终角色动画、动作捕捉与精确碰撞仍需后续制作。

## 在项目中继续编辑

进入「雨夜的修鞋摊｜流程设计器教程」，打开「武打对练 · 直拳格挡与低踢」节点。工程包含白方 27 个、蓝方 26 个人物关键帧，以及 6 个机位关键帧。

其他项目也可以复用：新建一个 3D 导演节点，打开本教程附带的 `武打对练-完整工程.json`，复制全部内容，点击「粘贴工程 → 导入此工程」。导入替换当前节点的场景，可以撤销恢复；已有重要工程先导出备份。文件导入仍可使用。

教程先从空场景手动设置护架和一记直拳，再明确展示导入完整对练，继续调整格挡、低踢、节奏和机位。完整 JSON 中的每一处动作都能在关节面板编辑。

## 动作安排

| 时间与关键帧 | 白方 | 蓝方 | 编排目的 |
| --- | --- | --- | --- |
| 0–2 秒，0/18/36/48 帧 | 保持护架，向前逼近 | 缩短距离、保持护架 | 先建立双方空间 |
| 2.75–3.46 秒，66/72/76/83 帧 | 短蓄力、左直拳、收臂 | 70 帧准备，76 帧外挡并侧移 | 准备略慢，发力短，对手有反应 |
| 5–5.5 秒，120/124/130/132 帧 | 补右拳，重新护架 | 双手护住上身，身体后让 | 延续第一轮试探 |
| 7.08–8.25 秒，170/176/180/186/198 帧 | 180 帧开始后撤，188 帧继续退步 | 提右膝、低踢、收腿落下 | 用距离和反应表现迫退 |
| 10–11.5 秒，240/248/256/264/276 帧 | 转体补拳，回收 | 侧闪、短反击，再拉开距离 | 第二轮交锋后结束 |
| 13–16 秒，312/336/383 帧 | 停步、放低护架 | 停步、收势 | 留可继承的结尾姿态 |

这是动作调度练习，双方拳脚不做精确接触解算。低踢前先收膝，踢出后收腿；白方沿退步路线回应，避免把“反击”做成独立循环动画。

## 从零做一个直拳

白方初始 `X=-1.05`、朝向 `90°`；蓝方初始 `X=0.9`、朝向 `-90°`。基础动作保持「站立」，关闭沿路线自动朝向与持续头部注视，便于直接设计姿态。人物的前方是自身 `+Z`，四肢前摆常用局部 X 负角度。

先做护架：白方左上臂 `X=-48°、Z=-18°`，左肘 `X=-70°`；右上臂 `X=-42°、Z=18°`，右肘 `X=-65°`。左大腿 `X=-12°`、左膝 `X=12°`，右大腿 `X=12°`、右膝 `X=10°`，躯干略向前倾。

| 帧 | 左上臂 X | 左肘 X | 操作 |
| --- | --- | --- | --- |
| 60 | -48° | -70° | 保留护架，记录当前关键帧 |
| 66 | -30° | -105° | 蓄力，肘向内收 |
| 72 | -86° | -12° | 发力伸臂，肩略向外打开 |
| 83 | -58° | -60° | 收臂，恢复控制 |
| 96 | -48° | -70° | 回到护架 |

在「当前预演帧」输入帧号，再修改关节角度，会自动记录当前帧。用「聚焦选择」看清人物；数字、滑杆和旋转环共用同一份姿态。转体、走位和肩肘可以在同一帧组合，身体姿态叠加在基础动作之上。

## 格挡与低踢

完整工程里，蓝方 76 帧的左上臂为 `[-75,-18,-38]`，左肘为 `[-50,0,0]`，躯干略后倾并转动，位置向 Z 侧面移动。先查看 70 帧的准备，再看 76 帧的外挡，不要只复制最终姿势。

| 蓝方帧号 | 右大腿 X | 右膝 X | 动作 |
| --- | --- | --- | --- |
| 170 | -32° | 90° | 提膝 |
| 176 | -55° | 52° | 腿开始展开 |
| 180 | -68° | 12° | 低踢顶点 |
| 186 | -36° | 78° | 收腿 |
| 198 | 12° | 10° | 恢复护架 |

支撑腿与身体高度要一起检查。示例在设计关键帧时调整高度，使支撑脚留在地面附近；运行时没有足部 IK 或自动锁脚。改变腿角度后，应重新检查高度和插值之间的脚底位置。

## 节奏、机位与保存

时间轴菱形包含位置、朝向和姿态。把 72 帧移动到 74 帧可延后发力顶点，Ctrl+Z 恢复；拖动可以移动，Alt 拖动复制。目标帧已有关键帧时会拒绝覆盖。发力段短，准备与回收稍长，避免每段等速。

摄影机 0/96/160/220/312/383 帧沿同侧缓慢移动，保持双方全身和退步空间。编辑视口可以自由旋转，最终输出以右下角摄影机监看为准。先保住手脚，再做推拉或绕拍。

保存工程，导出 JSON，再导出白模视频。白模为 H.264、1280×720、24 fps、16 秒，辅助线不会进入视频，没有声音。

## 教程制作与核验

浏览器操作通过 CUA 在实际 Edge 页面完成，采集原始界面帧和播放过程。FFmpeg 按讲解节奏剪辑，关节编辑处放大属性面板；停留时间经过编辑，不能当作真实操作耗时。最后附原速完整白模，慢放段明确标记。

在线 Yunxi 男声在本次运行中未返回音频，因此解说使用本机 Windows Microsoft Huihui 中文女声。逐句音频用 ffprobe 实测，字幕短句在各句实测区间内分配；这不是逐字 ASR 对齐。没有背景音乐，没有提交付费媒体任务。

已核对项目保存版本与工程导出一致，检查全部 384 帧的脚底高度，以及手、肘与自身头部球体的距离。该几何检查不覆盖身体所有部位、双方接触或任意用户改动。完整视听审阅与技术解码检查分别记录。

复现文件：`design.ts` 生成可编辑工程，`narrate.py` 生成本机解说，`produce.py` 剪辑实际浏览器采集帧并输出字幕和章节。浏览器采集另通过 CUA 完成，脚本不驱动浏览器，也不调用模型生成媒体。
