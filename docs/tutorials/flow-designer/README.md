# 流程设计器预览教程

片头明确注明：流程设计器为预览功能，尚未正式发布，界面和操作可能继续调整。

讲解从独立空白项目《雨夜的修鞋摊》开始，演示真实编辑、保存和画布操作。它是教程草稿，没有生成媒体。片尾打开已有《长安异闻录》第一卷·算命，展示完整项目设计和已有成片节选。素材与任务记录保留，没有重新提交付费媒体。

`produce.py` 负责配音、画面包装、剪辑、字幕、章节和验证；浏览器操作及界面采集通过 Codex 的 Edge 浏览器工具完成。界面按操作步骤采集后剪辑，配有焦点提示，不能将其记作连续屏幕录像。影片节选是现有视频，保留原声音。

源讲解稿见 `video-narration.md`。产物位于 `output/flow-designer-tutorial/`。
