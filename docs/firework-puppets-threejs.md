# 药发木偶旋转预演

项目内新增了一个 HTML + Three.js 预演页，开发服务启动后打开 `/demos/firework-puppets/index.html`。原来的药发木偶对照页增加了“操作3D旋转预演”入口。页面标注为实验预演，尚未正式发布。

这一版用程序化模型表现固定主竿、凤凰、笼架、圆轮、竖向花轮、四座悬挂戏台和红色挂饰。它适合先确定装置的空间、运动与燃放节奏，竹木细节、木偶雕刻和凤凰造型还可以替换为精细资产。

## 操作

1. 点击“查看高潮”，先观察默认编排。左键拖动画面绕装置观察，滚轮缩放，右键平移；“完整花树”保留观察方向并重新框入完整装置。
2. 在“选择运动组”里选择左侧竖向花轮，将转速设为24，方向选择正转。点击“继续播放”，金色轮缘标记和火花发射口会一起旋转。改为反转即可改变旋转方向。
3. 右侧花轮可以使用反方向。上、中、下层圆轮与上下两层悬挂戏台各自设置转速、启动时间、结束时间和初始角度，安排不同的运动节奏。默认编排依次启动下层、中层、上层圆轮。
4. 暂停后拖动时间轴，或输入预演时间，检查任意时刻。调整火花强度、颜色、下坠速度、横向风和薄烟；“本组火花”只关闭选中组的火花。
5. 配置自动保存在当前浏览器。需要留存版本时导出JSON，之后通过“导入配置”恢复。配置使用 `ruoyi-firework-puppets-v1` 格式，用于本页，不直接覆盖已有导演工作台工程。
6. 设置6—30秒时长，选择9:16或16:9，点击“导出预演MP4”。视频为720p、24fps、无声，从头渲染整段表演，保留观察方向并让完整花树入画。页面会提供回放和下载链接；自动下载未触发时可手动点击链接。使用支持H.264编码的新版Edge或Chrome。

导出的预演可作为AI视频的动作参考，精确控制轮架与火花的运动。最终国漫视频仍需单独制作和审阅，原来的国漫候选、参考素材与项目没有被替换。

## 实现

`src/features/firework-puppets/model.ts` 管理七个运动组、配置校验与确定性的运动公式。角度按转速累积，不在360度处截断，因此连续多圈旋转不会走最短路径。启动和停止各有短暂加减速。

`scene.ts` 将轮架挂到各自的Three.js Group中，主竿与底座保持固定。悬挂戏台随挑杆移动，通过反向补偿朝向保持木偶站立。火花在出生时记录世界坐标与速度，之后按重力和风计算位置，离开发射口的粒子不继续跟随轮架。粒子与拖尾使用固定容量缓冲区，砖面与笼架细杆使用实例化网格；预览DPR上限为1.5。

`export.ts` 使用项目现有的mediabunny逐帧编码路径，按每秒24帧的显式时间戳计算旋转与火花。导出期间暂停预览渲染，独立导出场景在结束或取消时释放资源。`main.ts` 连接操作面板、本地保存、配置导入与视频回放。

HTML位于 `public/demos/firework-puppets/index.html`，Three.js及编码器打包在同目录的 `app.js` 中，不依赖CDN。修改引擎后运行 `npm run build:firework-puppets` 更新静态脚本；`npm run build` 会先执行这一步，再做类型检查和Vite构建。

## 已验证的范围

- 四项测试覆盖连续多圈与反向旋转、发射口和真实Three.js变换一致、粒子轨迹可重复定位与重力变化、配置导入校验。
- 实际页面验证了播放暂停、调整转速与方向、单组火花开关、全局强度归零、配置导入和画布拖动视角。
- 390×844视口下无横向溢出；这是浏览器窄屏检查，未替代真机触控测试。
- 15秒的720×1280竖屏预演和6秒的1280×720横屏预演均在浏览器播放至结尾，播放器未报告错误；检查了代表性火花画面。这不等同于完整人工逐帧动作审阅。
- 浏览器自动化未能取得Blob下载事件，因而没有对保存到磁盘的MP4做FFmpeg解码验收。页面内生成、视频尺寸、时长及回放已确认，保留了手动下载链接。

更细的测试记录位于 `output/firework-puppets/threejs-validation.json`。这版尚未把独立运动组写入已有导演工作台工程模型，也未验证手机触控或长期运行时的显存情况。
